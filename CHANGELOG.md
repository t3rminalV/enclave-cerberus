# Changelog

All notable changes to Cerberus are documented here.

This file is maintained by `standard-version` from Conventional Commit messages.

## 0.1.0 - 2026-04-15

### Features

- Added a staff-only version link and changelog page.
- Added an admin-controlled application anonymisation mode with an admin-only full-data export.
- Required emergency contact details before volunteers can apply or submit applications.
- Expanded audit logging to show actions from all users.

### Bug Fixes

- Fixed alert spacing when alert variants are used directly.
- Fixed avatar URLs on pages that render related users.
